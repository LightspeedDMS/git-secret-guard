# lib/integrations: other tools git-secret-guard sets up

CLI only. One folder per tool: `smartgit/` (the SmartGit executable settings) and `desktop/` (the GitHub Desktop git link).

- **May depend on:** `lib/core/`, `lib/gitup/`, `lib/install/`, and the other CLI contexts as `bin/git-secret-guard` loads them.
- **Never loaded by the hook.**
